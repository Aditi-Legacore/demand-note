# Notes:
# - Embedding engine (chromadb + sentence-transformers) is fully optional
#   Pipeline will skip it gracefully if not installed
# - For CLI/batch deployment (no web service needed)
#
# IMPORTANT: System Dependencies (not in pip)
# Two system packages required for OCR and PDF rendering:
#
# 1. Tesseract OCR engine:
#    Windows:
#      choco install tesseract
#      or download: https://github.com/UB-Mannheim/tesseract/wiki
#    macOS:
#      brew install tesseract
#    Linux (Ubuntu/Debian):
#      sudo apt-get install tesseract-ocr
#    Linux (CentOS/RHEL):
#      sudo yum install tesseract
#
# 2. Poppler (for pdf2image):
#    Windows:
#      choco install poppler
#      or download: https://github.com/oschwartz10612/poppler-windows/releases
#      Set POPPLER_PATH env variable if installed manually
#    macOS:
#      brew install poppler
#    Linux (Ubuntu/Debian):
#      sudo apt-get install poppler-utils
#    Linux (CentOS/RHEL):
#      sudo yum install poppler-utils
#
# Note:
# - pytesseract is just a Python wrapper; Tesseract binary must be installed
# - pdf2image requires Poppler binaries on your system
# - If either is missing, PDF extraction will gracefully fall back to PyMuPDF
# - All standard library modules are included by default
